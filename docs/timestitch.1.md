# NAME

*timestitch* 


# SYNOPSIS

*timestitch* [OPTIONS] [TARGET]


# DESCRIPTION

*timestitch* generates timeline and journal files from a file list.


# EXAMPLES


# OPTIONS

--config <CONFIG>

    specify the configuration file. See _timestitch_(5)

-h, --help

    print help

-V, --version

    print version information
